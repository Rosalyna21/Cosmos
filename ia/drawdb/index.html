DrawDB

Dessine tes schémas de bases de données à la souris, et laisse l'outil générer le SQL.

DrawDB est un éditeur de diagrammes entité-relation open source et gratuit qui tourne entièrement dans le navigateur : tables, relations, cardinalités, puis export du script SQL (PostgreSQL, MySQL, SQLite…). Aucun compte requis, tes diagrammes restent stockés localement.

Je m'en sers pour concevoir les schémas des bases de Cosmos (budget, dashboard) avant de les créer — et toi, tu peux l'utiliser pour n'importe quel projet.

Astuce : commence par tes tables principales, ajoute les relations en glissant d'une clé à l'autre, puis Export → SQL. Le fichier généré se lit très bien pour apprendre.

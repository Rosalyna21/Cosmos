# Cosmos 🌸✨

**Cosmos** est ma plateforme personnelle : un petit coin de web où je rassemble, au même endroit, des calculateurs d'argent apaisés, un atelier pour dessiner, et des outils data & IA — le tout dans le navigateur, sans compte ni installation.

🔗 **En ligne : [rosalyna21.github.io/Cosmos](https://rosalyna21.github.io/Cosmos/)**

Chaque projet est une étoile ; l'ensemble forme une constellation qui grandit petit à petit.

## Ce qu'on y trouve

- **Finances** — une calculatrice et des simulateurs (intérêts composés, mensualité de prêt, objectif d'épargne) pour poser ses chiffres et décider en connaissance de cause.
- **Détente** — un atelier de dessin libre, et d'autres surprises créatives à venir.
- **Outils data & IA** — des outils gratuits qui tournent **en local** (agrégateur CSV, synthèse vocale…), et d'autres en préparation.

## Ce en quoi je crois

- **Tes données t'appartiennent.** Pas de compte, pas de serveur, pas de traçage : tout vit dans ton navigateur, et tu peux l'emporter quand tu veux.
- **Aucune leçon à donner.** Des repères, jamais des règles — l'important est de choisir en connaissance de cause.
- **Ça grandit.** Chaque mois, quelque chose de neuf pousse ici ; ce qui existe s'améliore, ce qui manque finit par arriver.

## Sous le capot

Site **100 % statique** (HTML / CSS / JavaScript pur), sans framework ni dépendance :

- fonctionne une fois la page chargée, sans rien envoyer en ligne ;
- **polices auto-hébergées** — aucun appel à un service tiers ;
- thème clair / nuit mémorisé localement ;
- hébergé sur **GitHub Pages**.
